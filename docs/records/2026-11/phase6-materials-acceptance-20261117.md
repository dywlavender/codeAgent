## 资料管理与结构查询

- 手动生成的 AST 版本只含 `index.db` 和 `metadata.json`。本次示例索引包含 16 个代码文件、109 个符号和 1 条已解析关系。
- 浏览器搜索 `WithdrawApplicationService.apply`，展开到 `validatePreconditions`，点击 `CALLS` 连线打开 Java 原文的调用位置。修改演示源码后索引显示待更新，服务端拒绝继续查询。另一工程不能使用此版本。Java 继承、实现、歧义与 TypeScript 定位另由测试覆盖。
- 系统导航首轮草稿只查看了目录，因没有目标源码 Read 记录被拒绝。草稿任务明确采用定位入口再直接 Read 的步骤后，第二轮读到 6 份 Java 源码和 2 份其他文件，耗时 125.9 秒。人工删去关于未发现架构层的宽泛判断与一条无效链接，发布简化后的导航。发布前生效预览未包含草稿，发布后展示正式规则。按系统预览仅包含所选系统，按应用关联仓库预览可包含同仓另一系统的导航。
- 上传演示需求并在浏览器查看原文。业务文档投影依次显示未导入、已同步、待更新。原文更新后投影仍待更新，`combined` 问答读取到新原文。浏览器 Trace 的“本轮资料”分开显示已装配、实际原文交付数和结构工具调用次数。
- 从浏览器切换到隔离对照工程，导航、业务原文、AST 和原始资料均显示初始状态。
