# 融商贷项目总览

核对日期：2026-09-06（按业务基线编写规范改写：本页只留整体认识与调查地图，规则口径见需求文档，实现细节以源码为准）。范围：项目配置中的四个系统、五个应用。

## 项目与系统职责

融商贷是小微企业经营贷款平台：一份授信下多次提款，每笔借款独立选择期限、还款方式与支付路径。中台为独立旁挂服务，Fineract 保持原版、经 REST 命令 API 使用。

| 系统 | 应用 | 业务职责 |
| --- | --- | --- |
| 渠道系统 | 融商贷渠道后端／channel-service | 渠道开放规则、字段转换、申请入口、展示状态聚合 |
| 贷款中台系统 | 融商贷贷款中台／loan-middle | 额度台账、报价、提款与还款编排、补偿查单；业务最终状态的唯一裁判 |
| 贷款中台系统 | Fineract 贷款中台服务／fineract-backend | 借据生命周期、还款计划、还款金额分配、结清判定（原版 1.14.0） |
| 外部模拟系统 | 外部系统模拟服务／external-simulator | 模拟审批/付款/扣款的执行结果、回调与查单 |
| Fineract 开源贷款平台 | Mifos X 平台 Web 前端／mifos-web | 运营页面（原版） |

协作链：客户前端 → 渠道后端 → 贷款中台 → 外部模拟服务；贷款中台 → Fineract。三段业务编号（渠道申请号 → 中台业务单号 → 外部流水号）各存各的系统，只经接口传递。

## 关键术语对照与易错点

- 业务说"提款"，接口与代码是 drawdown；Fineract 侧的"放款"是 disburse。本项目没有"提款＝withdraw"的用法。
- "外部付款成功"不等于"业务成功"：外部结果只是数据，提款成功以中台账本为准；回调成功也不代表中台后续处理完成。
- 借款"结清"是还款入账后由 Fineract 自动判定的状态，不是人工设置。
- 业务词"担保利率"统一指担保费率，属于历史别名。
- 前端展示状态可以合并多个内部状态（都显示"处理中"），映射关系保留在渠道侧，可追踪。
