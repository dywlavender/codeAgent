# 接口与状态约定

版本：V1 阶段 2。分三部分：三系统间契约（自研）、客户前端契约、Fineract 原生接口约定。字段级完整契约见项目 `docs/接口契约-阶段2.md`（同一内容维护于本文件，调查以本文件与源码为准）。

## 一、标识链与通用约定

- 标识链：`channelRefNo`（CHN-，渠道生成）→ `bizOrderNo`（DD-提款 / RP-还款 / CR-授信，中台生成）→ `extSerialNo`（EXT-P/EXT-D，模拟服务生成）。
- 金额单位元、两位小数；期限单位月；日期 ISO-8601。
- 幂等键：中台→外部提交按 `bizOrderNo`；外部→中台回调用 `extSerialNo`+`bizOrderNo`；重复请求返回首次结果，不产生新记录。

## 二、三系统间契约（阶段 2）

### 渠道后端 → 中台（middle，端口 8092）

| 操作 | 端点 | 说明 |
| --- | --- | --- |
| 可选条件 | `GET /middle/api/v1/drawdowns/options?creditId=` | 返回产品列表与 `availableAmount` |
| 报价试算 | `POST /middle/api/v1/drawdowns/quote` | 快照 30 分钟有效 |
| 提款申请 | `POST /middle/api/v1/drawdowns` | 202 返回 bizOrderNo |
| 提款结果 | `GET /middle/api/v1/drawdowns/{bizOrderNo}` | 含 payments、booking |
| 还款申请 | `POST /middle/api/v1/repayments` | type: DUE/EARLY_PRINCIPAL/EARLY_SETTLE |
| 还款试算 | `POST /middle/api/v1/repayments/prepayment-quote` | |
| 还款结果 | `GET /middle/api/v1/repayments/{bizOrderNo}` | 含 allocation 分配明细 |

错误码：`QUOTE_EXPIRED`、`AMOUNT_CHANGED_NEED_REQUOTE`、`LIMIT_INSUFFICIENT`、`TERM_NOT_SUPPORTED`、`PRODUCT_NOT_OPEN`。

### 中台 ↔ 外部模拟服务（simulator，端口 8093）

| 操作 | 端点 | 说明 |
| --- | --- | --- |
| 提交付款 | `POST /sim/api/v1/payments` | 幂等按 bizOrderNo |
| 提交扣款 | `POST /sim/api/v1/deductions` | |
| 查结果 | `GET /sim/api/v1/payments/{extSerialNo}`、`GET /sim/api/v1/deductions/{extSerialNo}` | 返回真实终态 |
| 回调 | `POST {middle}/middle/api/v1/callbacks/external-result` | type: PAYMENT/DEDUCTION，result: SUCCESS/FAILED |
| 场景配置 | `PUT /sim/api/v1/scenarios/{bizOrderNo}` | SYNC_SUCCESS / SYNC_REJECT / ASYNC_SUCCESS_DELAY / ASYNC_FAIL / NO_CALLBACK_NEED_QUERY |

### 中台状态

- 提款业务单：`PROCESSING → EXTERNAL_SUCCESS_BOOKING_PENDING → SUCCESS | FAILED`（提交前可 `CANCELLED`）；付款指令状态 `TO_SUBMIT/PROCESSING/SUCCESS/FAILED/RESULT_UNCONFIRMED`；入账状态 `TO_BOOK/BOOKED/RETRY_NEEDED`。
- 还款订单：`PROCESSING → SUCCESS | FAILED`；分配明细含 principalPortion / interestPortion / feePortion。

## 三、客户前端 ↔ 渠道后端（channel-service，端口 8091）

`GET /api/drawdown/options?channelId=&creditId=`、`POST /api/drawdowns?channelId=`、`GET /api/drawdowns/{channelRefNo}`、`POST /api/repayments?channelId=`、`GET /api/repayments/{channelRefNo}`。渠道错误码：`CHANNEL_AMOUNT_LIMIT`、`CHANNEL_TERM_LIMIT`、`PRODUCT_NOT_OPEN`。展示状态映射：中台 `PROCESSING/EXTERNAL_SUCCESS_BOOKING_PENDING` 等处理中状态对外统一为 `PROCESSING`，原始状态保留在渠道申请单。

## 四、Fineract 原生接口（fineract-backend，1.14.0）

- API 前缀 `/fineract-provider/api/v1`；租户头 `Fineract-Platform-TenantId`；动作经 `?command=` 查询参数。
- 中台使用的端点：`POST /loans`（创建借据）、`POST /loans/{id}?command=disburse`（放款）、`GET /loans/{id}?command=calculatePrepayment`（提前结清试算）、`POST /loans/{id}/transactions?command=repayment`（还款入账）、`GET /loans/{id}/transactions/{tx}`（分配明细）。
- 贷款状态 LoanStatus：100 提交 / 200 审批 / 300 生效 / 600 义务履行结清 / 700 超额；状态转移由 `DefaultLoanLifecycleStateMachine` 按 `LoanEvent` 校验。
- 摊销方式映射：`EQUAL_PRINCIPAL→amortizationType 0`、`EQUAL_INSTALLMENTS→1`；计息方式 `interestType 0`（余额递减）；还款频率类型 2（月）；`repaymentStartDateType 1`（按放款日起算）。
