# 系统代码导航

## 导航摘要

- 写下本系统定位入口和继续追查的通用方法，压缩为几条可执行的线索。
- 只写本系统实际采用的代码组织惯例。跨应用的下游关系仍需查源码确认。

## 常见入口

说明如何定位本系统实际采用的入口，例如路由、注解、注册表、任务入口或消息订阅。按需补充输入、输出、转换和校验代码的常见位置。

## 分发和异步处理

说明遇到间接分发、异步消息或批任务时，应从什么配置、注册点或处理器继续调查。

## 维护约定

安装时将本文件保存为工程数据目录下的 `knowledge/system-guides/<systemId>/SYSTEM.md`。只有应用有独特入口或分发方式时，才另建同目录下的 `applications/<applicationId>.md`，只写与通用规则不同的地方。应用文件也可使用「导航摘要」小节。

系统、应用和模块位置取自现有工程配置。导航文档维护查找规则，新增接口、字段和普通业务方法无需逐项登记。
