# 主问答组合使用资料（2026-11-02）

用户指出基础资料、AST 和业务补充可以共同使用，要求取消问答页的互斥选择。此前三种模式来自对照实验：基础资料始终提供，AST 与业务补充互斥；这种分组不再用于日常问答默认配置。

## 实现

- 主问答默认 `combined`：源码、README、需求、业务补充知识、已有代码地图和可用的手动 AST 同时可检索，按问题需要读取。
- AST 挂载到 `knowledge/ast/`，自动代码地图仍在 `knowledge/generated-code-map/`。两者在来源清单和事实目录中均属于结构导航，不作为业务行为证据。
- 查询和页面只读取 AST 状态及已有版本。未生成或待更新时继续使用其余资料，不创建新索引或 AST。可用版本变化时重新建立模型会话。
- 页面移除资料三选一；现有仓库调查范围菜单显示各资料状态。浏览器旧 queryMode 设置不再限制新问题。历史回答保留原模式，新追问使用组合资料。
- 每轮稳定轨迹记录实际授权目录、AST 状态与版本；旧回答未使用 AST 时不补入会话后来采用的版本。
- none/backbone/ast 及五组独立实验的来源隔离保持，用于历史兼容和显式对照。
