# 前端设计说明

前端统一使用 `frontend/src/design-tokens.css` 中的颜色、字体、间距和组件变量，业务页面不另建局部视觉体系。

## 页面结构

- **Agent 问答**：常规对话界面，答案展示当前代码、业务基线和需求证据。
- **浏览知识库**：查询当前代码 Symbol 和业务知识实体/关系。
- **业务知识维护**：管理员导入自然语言业务基线，查看原文、关系和调查入口。
- **知识图谱**：查看业务实体、关系、应用和调查入口的只读投影。

## 业务知识维护页面

页面只有一个写操作：

1. “导入业务基线”：调用模型把 Markdown 结构化为业务实体和关系，并校验原文证据。

详情展示知识类型、定义、结构化信息、原文来源、业务关系和调查入口。调查入口只保存应用、入口类型和入口名称；具体 Symbol、方法和源码位置由问答时按当前代码索引解析。

如果模型不可用，页面会显示导入错误；不会悄悄切换到另一套知识模型。

## 知识图谱

图谱只展示有检索作用的长期关系：

```text
业务实体 → 业务关系
业务实体 → 调查入口 → 应用
```

代码 Symbol、调用链和代码 Evidence 不在图谱中长期保存，它们由 Agent 在问答期间实时调查。
