# 前端设计说明

前端统一使用 `frontend/src/design-tokens.css` 中的颜色、字体、间距和组件变量，业务页面不另建局部视觉体系。

## 页面结构

- **Agent 问答**：常规对话界面，答案展示代码和业务文档证据。
- **知识查询**：查询代码符号和功能知识。
- **功能知识**：管理员扫描功能文档、查看入口定位、关键表和 Agent 分析。
- **知识图谱**：查看功能、工程、入口代码、关键表和标签的检索关系。

## 功能知识页面

页面只有两个主要动作：

1. “更新知识库”：扫描配置目录，重建所有功能的检索索引，并在模型可用时分析流程和规则。
2. “重新分析”：只分析当前功能，不要求管理员重新填写内容。

详情按以下顺序展示：

- 功能说明、标签与场景；
- 工程与入口类及定位状态；
- 关键表及数据作用；
- Agent 生成的流程与规则；
- 分析状态、覆盖数量和代码证据。

入口状态统一使用“已定位、多个候选、未定位、等待定位”。模型未配置时显示“索引完成”，而不是把确定性索引包装成模型分析结果。

## 知识图谱

图谱只展示有检索作用的关系：

```text
功能 → 工程 → 入口代码
功能 → 关键表 ← 读写代码
功能 → 标签
```

全局图不能替代功能详情。默认优先围绕搜索命中的功能显示相邻节点，避免把所有代码节点一次性铺满页面。
