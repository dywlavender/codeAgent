# 前端设计说明

前端统一使用 `frontend/src/ui/tokens.css` 中的颜色、字体、间距和组件变量，业务页面不另建局部视觉体系。

## 页面结构

- **Agent 问答**：常规对话界面，答案展示当前代码、业务基线和需求证据。
- 每轮问答提供“查看调用轨迹”：侧栏抽屉按模型、工具和程序调度查看完整记录，能查看请求消息、公开响应、工具参数与原文、调查事项，并导出 JSON。运行中定时刷新；失败和取消记录保留。轨迹状态属于页面自身状态，切换工程或关闭时取消旧请求。
- Pi 问答的「系统提示词」页显示已归档的实际生效文本、工具说明和装配片段。仅有装配内容时提示观测状态。
- **浏览知识库**：查询当前代码 Symbol 和业务知识实体/关系。
- **业务知识维护**：管理员编辑业务 Markdown，按需更新结构化视图。
- **知识图谱**：默认查看业务实体、关系、应用和调查入口的只读业务关系投影；接口调用链保留为次级技术视图（`#/graph?view=calls` 可直达）。

## 知识中心（资料管理台）

问答工作台与资料管理台分离：问答页只保留对话与调用轨迹，不混入资料状态、配置或生成入口；资料的配置、生成、预览都在资料区各自页面完成。左侧导航为扁平菜单：问答、资料总览、系统导航、业务知识、AST 索引、知识图谱、效果验证、工程设置；资料区页面顶栏显示「资料」面包屑。

资料总览（`#/materials`，`features/materials/MaterialsPage.jsx`）是管理台入口：优先显示待处理事项（系统导航待配置、业务投影待更新/失败、AST 待更新/失败，由 `/api/materials` 汇总结果在客户端推导），再以卡片展示系统导航、业务知识、AST 索引、知识图谱、代码地图（来自 `sources` 中 `kind=code_map`）与原始资料的状态、规模、最近更新和快捷动作；动作只跳转到对应维护页或打开上传/预览，不在总览页内做编辑与生成。原始资料保留上传、抽屉预览与下载。系统导航页按系统和应用打开编辑器，区分「内容预览」与「编辑 Markdown」；AI 生成草稿与发布导航位于页头，草稿发布后才参与问答；实际生效的导航常驻右栏，选中系统或应用时显示对应视角，可切换为仓库视角。AST 页默认「关系探索」，按符号逐层展开并在右栏查看源码位置，未解析调用以虚线线索节点展示；「索引管理」为次级标签，生成/重新生成在该页完成。业务知识页的更新投影在该页右栏执行。原始资料列表可预览 Markdown、文本、JSON、DOCX 等文件。PDF、Excel 可下载原件查阅。调用轨迹的「本轮资料」按运行记录显示装配、原文交付或结构工具调用。

## 业务知识维护页面

业务知识页以 Markdown 原文为中心：左侧文档列表，中间区分「阅读预览」与「编辑 Markdown」，右栏显示结构化投影状态并执行显式导入（更新投影）。实体与关系的浏览归知识图谱页；结构化视图不再是与原文平行的维护对象。

已保存的文档可发起 AI 修订建议。建议窗口显示所选原文、建议正文、依据和待业务确认事项。管理员可直接确认保存，或回到编辑器调整后保存。

如果模型不可用，页面会显示导入错误；不会悄悄切换到另一套知识模型。

## 知识图谱

“业务关系”是默认视图，展示有检索作用的长期关系：

```text
业务实体 → 业务关系
业务实体 → 调查入口 → 应用
```

“接口调用链”作为次级技术视图，独立读取已显式准备的工程契约索引。选择入口后从左到右排列接口、服务方法、HTTP 客户端和远端接口；箭头表达调用方向，HTTP 连接突出显示。未解析或过期的连接用虚线及状态提示区分，进入页面不生成 AST。

点击节点或连线在侧栏抽屉查看源码依据、行号和版本，远端接口可作为新入口继续查看。支持缩放、适应画布与拖拽平移，接口选择可按路径、方法名和应用搜索。主图显示已有的返回依赖调用，不将其表述为完整执行轨迹。源码依据与业务知识保持各自来源，不把当前代码关系复制进人工业务知识表。
