# 融商贷业务补充知识

本目录只保存源码、原始需求和普通项目文档难以可靠消歧的项目特有语义。它不是项目总览、调用链或代码目录；当前实现必须回到源码核实。

适用范围：`complex-loan-validation` 当前固定源码快照，以及阶段 2—3 的提款、还款和额度验证题库。

主要依据：`requirements/产品规则.md`、`requirements/接口与状态约定.md`、`requirements/系统职责.md`、`docs/三系统边界设计.md`。如果本目录与原始需求或源码冲突，应分别报告冲突，不把补充知识当作实现证据。

文件职责：

- `terminology.md`：业务词与代码词、历史叫法的消歧。
- `boundaries.md`：容易把系统职责或状态含义理解错的边界。
- `cross-system.md`：源码目录不一定直接表达的跨系统业务关系。
- `exceptions.md`：共享额度、冻结和降额等容易遗漏的特殊规则。

每条内容都应能回答：如果没有它，调查方向或业务理解可能错在哪里？否则不要继续写入本目录。
